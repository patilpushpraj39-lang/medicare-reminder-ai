# 💊 Medicare Reminder AI

Medicare Reminder AI is a modern web application designed to help users manage their medicines and medication schedules in a simple and organized way.

The project focuses on providing a clean user experience, reliable medicine tracking, responsive design, and cloud-based data management.

## 🌐 Live Demo

🔗 https://medicare-reminder-ai-one.vercel.app/

## ✨ Features

- Add and manage medicines
- Create medication reminder schedules
- Organize medicine-related information
- Responsive user interface
- Modern dashboard experience
- Secure cloud-based data storage
- User-friendly navigation
- Mobile-friendly design
- Real-time data handling
- Deployed as a production web application

## 🛠️ Tech Stack

### Frontend
- TypeScript
- React
- Vite / TanStack
- CSS
- Modern component-based UI

### Backend & Database
- Supabase

- Supabase APIs
